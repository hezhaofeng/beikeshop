# 商品定制

为指定商品分类及其全部子孙分类配置多个前台定制输入项，并将定制值保存到购物车和订单。

## 安装

1. 同步 `plugins/ProductCustomization`、核心购物车扩展文件和 `database/migrations/2026_08_21_000001_add_line_key_to_cart_products.php`。
2. 先执行 `php artisan migrate --force`，写入购物车通用 `line_key` 字段。
3. 在后台安装并启用“商品定制”插件；后台安装过程会自动执行插件迁移，无需额外执行 `plugin:migrate`。
4. 执行 `php artisan optimize:clear`。
5. 在后台“商品 > 商品定制”创建模板、添加字段并关联商品分类。只保存直接选择的分类；选择父分类后，子孙分类商品会自动继承该模板。

## 多语言

- 前台字段名称、占位提示、页面提示、校验错误和定制摘要会按买家当前语言显示。
- 字段配置提供中文与英文名称、占位提示；未填写英文时自动使用中文。
- 下拉字段提供中文和英文选项，两侧按行一一对应。新配置使用稳定内部值，因此切换中英文不会将同一选项拆成不同购物车明细。
- 历史单语言下拉选项保持兼容，仍按原值展示和校验。

核心购物车扩展用于区分同一 SKU 的不同定制值；插件自身负责配置、校验、购物车快照和订单快照。
