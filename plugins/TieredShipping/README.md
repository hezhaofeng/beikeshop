# 阶梯运费

本插件提供一个配送方式，可在后台按三种规则之一计算运费：

- 订单金额满额免运费：低于门槛收取基础运费，达到门槛后免运费。
- 订单金额阶梯运费：使用不高于订单金额的最高阶梯；没有命中任何阶梯时收取基础运费。
- 商品件数满额免运费：低于件数门槛收取基础运费，达到门槛后免运费。

金额和件数均基于结算时已选中的商品。金额为商品小计，不含运费；件数为商品数量之和。

## 使用方式

1. 在后台“插件”中安装并打开“阶梯运费”。
2. 设置基础运费，选择一种计费方式并填写对应门槛或阶梯。
3. 保存后在结账页选择“阶梯运费”。若不再使用固定运费，可停用 `FlatShipping`，避免顾客看到多个配送方式。

例如基础运费为 18，阶梯配置为“满 50 收 12、满 100 收 8、满 200 收 0”时：订单金额低于 50 收 18，50 至 99.99 收 12，100 至 199.99 收 8，满 200 免运费。
