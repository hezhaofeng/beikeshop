# 顶部公告

通过 `header.top.language.after` 钩子，在默认主题的语言/货币与邮箱之间添加单行公告，不修改核心或主题。使用原生插件管理表单和 settings 存储，无数据库迁移、无 npm 构建、无外部服务。

## 设置

1. 将整个 `plugins/TopNotice/` 目录同步至网站同名目录。
2. 在网站根目录执行 `php artisan optimize:clear`。
3. 后台插件管理中找到“顶部公告”，安装并进入编辑。
4. 填写“默认公告内容”。所有语言通用一段英文时只需填这里；各语言单独文案填写在“公告内容”中，留空自动回退到默认内容。
5. 选择显示范围（默认仅首页）、滚动或省略、颜色、字号、可选完整 HTTP(S) 跳转链接。
6. 可选填写开始、结束时间，格式 `YYYY-MM-DD HH:mm:ss`，按网站 `config('app.timezone')` 时区解释，任一项可单独留空。
7. 将原生“状态”设为开启并保存。未启用或当前语言及默认内容均为空时不展示。

示例默认内容：

> We are currently on the National Day holiday; all orders will resume shipping on October 4, 2026. If you have any questions, please contact us via email.

日期仅为示例，请按实际假期调整。结束时间为不包含边界，例如设为 `2026-10-04 00:00:00`，到该时间起不再显示。

## 展示行为

- 短文居中，长文在剩余宽度内单行往返滚动，两端停留约 1.8 秒。
- 鼠标悬停、键盘聚焦、触摸期间暂停；滚动模式支持手动横向滑动。
- 尊重系统“减少动态效果”设置，此时停止自动滚动，仍可手动滑动。
- 省略模式以省略号截断；完整文本保留于标题提示和可访问文本中。
- 背景色仅影响公告自身；原有语言、货币、邮箱继续保留。窄屏可用宽度取决于这些控件所占空间。
- “全站”仅涵盖使用该公共头部钩子的页面，独立收银台等模板不受影响。
- 定时条件在服务端渲染时判断，已打开页面需刷新；如另有整页/CDN 缓存，需同步调整缓存有效期或清除对应页面缓存。

## 验证与部署范围

生产同步完整 `plugins/TopNotice/`；README 可选，`tests/Unit/TopNotice/` 不必同步。依赖当前项目的本地插件加载能力和默认头部钩子。

安装保存后检查首页、多语言切换、非首页范围、手机宽度、长短文、暂停与链接；关闭状态后公告应消失。颜色需保证文字与背景可辨认。

无需改动原生代码或提交前端编译产物。若生产使用常驻 PHP 服务，按现有部署方式重载进程使插件入口生效。

隔离单元验证：`php vendor/bin/phpunit --no-configuration --bootstrap vendor/autoload.php tests/Unit/TopNotice`
